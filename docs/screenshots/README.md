# Screenshots

Drop up to three high-value screenshots here and they'll show up in the main
[README](../../README.md) (each is referenced by filename, commented out until
the file exists):

| Filename | Suggested shot |
| --- | --- |
| `tracker.png` | The public tracker page with a few bets showing, filters visible |
| `insights.png` | The Insights page — calendar or breakdowns tab, ideally with the P&L chart visible |
| `admin-add-bet.png` | The admin "Add Bet" form, or the screenshot-import preview |

Keep them reasonably small (crop to the relevant area, ~1200px wide is plenty)
so the README stays fast to load.
